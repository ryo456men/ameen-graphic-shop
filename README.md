# Ameen Graphic Design Shop

A fully-featured, single-page application for a graphic design studio. Built with vanilla HTML, CSS (Tailwind), and JavaScript.

## Features

- **Portfolio Management** - Showcase your design work with images and embedded videos
- **Service Packages** - Define and manage service offerings with pricing
- **Discount Codes** - Create promotional codes for clients
- **Chat System** - Client messaging system (saved locally)
- **Contact/Inquiries** - Contact form and inquiry management
- **Admin Dashboard** - Secure admin area for managing all content
  - Edit site settings, branding, and contact info
  - Manage portfolio, services, and discounts
  - View and respond to client messages and inquiries
  - Import/export data backups

## How to Use

1. Open `index.html` in a modern web browser
2. Navigate to "Admin" to access the dashboard (requires authentication)
3. Create an admin account or use the default admin email
4. Edit your site content, portfolio, and services

## Admin Authentication

The site uses secure admin authentication. Sign in with the configured admin email to access the admin dashboard.

## Data Storage

All data is stored locally in your browser's localStorage. This means:
- No backend server required
- Data persists across browser sessions
- Can import/export JSON backups from the admin panel

## Browser Support

Works on all modern browsers that support:
- ES6 JavaScript
- CSS Grid & Flexbox
- LocalStorage API
- Fetch API

## Built With

- **HTML5** - Semantic markup
- **CSS** - Tailwind CSS v4
- **JavaScript** - Vanilla JS (no frameworks)
